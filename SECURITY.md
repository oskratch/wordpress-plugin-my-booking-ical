# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | Yes       |

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Use GitHub's [private vulnerability reporting](https://github.com/oskratch/wordpress-plugin-my-booking-ical/security/advisories/new) feature instead. This keeps the details confidential until a fix is released.

Include as much detail as possible:
- Description of the vulnerability and its potential impact
- Steps to reproduce
- WordPress and PHP versions affected
- Suggested fix if you have one

You can expect an acknowledgement within 48 hours and a fix or mitigation plan within 14 days for confirmed vulnerabilities.
